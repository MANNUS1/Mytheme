# Mapa de Arquitectura - Mytheme

## Estructura de Módulos SCSS
- `src/theme.scss`: Punto de entrada principal para compilación vía `dart-sass`.
- `src/features/floating-sidedock.scss`: Controla los sidebars como tarjetas flotantes acrílicas activadas exclusivamente por atajos nativos, eliminando interferencias de hover por ratón.
- `src/app/tabs.scss`: Estilos de pestañas y barra superior.
- `src/app/sidedock.scss`: Estructura interna de los paneles laterales y file explorer.
- `src/layouts/cupertino.scss`: Tokens de diseño, radios de ventana y sombras estilo Cupertino.
